Project Overview

MedRAG AI is an advanced, integrated medical assistant designed to democratize access to preliminary diagnostic tools. It bridges the gap between complex medical data (text, imaging, audio) and actionable insights by combining three distinct AI disciplines:

Generative AI

Retrieval-Augmented Generation chatbot fine-tuned for safe, patient-centric communication.

Computer Vision

Deep Learning model detecting 14 chest pathologies with Explainable AI (Grad-CAM).

Audio Diagnostics

Signal processing unit analyzing respiratory biomarkers from cough and breath.

Module 1: RAG Chatbot

Custom-trained version of Mistral-7B, optimized for patient-doctor interactions using QLoRA and Unsloth.

Training Details

  • > Base Model: Mistral-7B-Instruct-v0.2
  • > Dataset: mahfoos/Patient-Doctor-Conversation (~3k)
  • > Rank (r): 16 | Precision: 4-bit
  • > Safety: Explicitly trained to refuse prescribing medication.
LLM PINECONE LANGCHAIN QLoRA

Tech Stack

Backend: FastAPI, Uvicorn, PyTorch, Transformers, LangChain.

Database: SQLite (User/History), Pinecone (Vector).

Frontend: Vanilla JS, CSS3 (Noir Theme), Canvas API.

FASTAPI JWT

Module 2: Vision

Automated radiology screening using DenseNet121 trained on CheXpert (224k images).

Capabilities

  • > 14 Pathologies (Pneumonia, Effusion, etc.)
  • > U-Ones Policy for uncertainty.
  • > Grad-CAM XAI Heatmaps.
PYTORCH OPENCV DENSENET

Module 3: Voice Diagnostics

Non-invasive diagnostics via spectral analysis. The ensemble CNN-RNN model decomposes audio into Mel-Spectrograms to identify micro-patterns in coughs and breaths.

Architecture

  • > Input: 3 Samples (Cough, Breath, Speech)
  • > Preprocessing: Librosa Mel-Spectrograms (128x128)
  • > Model: CNN (Spatial) + LSTM (Temporal)
LIBROSA CNN-LSTM DSP

API Endpoints

Method Endpoint Description

POST/chatSends query to LLM; returns RAG response.
POST/analyze_xrayUploads image; returns probabilities + Heatmap.
POST/diagnoseUploads 3 audio files; returns respiratory analysis.
POST/uploadIngests PDF/TXT into Vector Database.
